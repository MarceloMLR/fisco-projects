# Módulos de exemplo dos testes de arquitetura

Estes módulos existem só para provar que cada regra de arquitetura aceita o código certo e aponta a violação. `ValidModule` e `OtherModule` seguem todas as regras; cada um dos outros quebra exatamente uma regra, indicada pelo nome (`BrokenKernel` e `BrokenPersistence` fazem o papel do núcleo e da persistência compartilhados). Eles não fazem parte da aplicação.
